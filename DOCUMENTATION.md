# Nutrix AI: Project Directory Map

This document serves as your cheat sheet for navigating the codebase. Because frameworks like Flutter strictly enforce folder names (like `lib`), we cannot rename them without breaking the app. Use this map to quickly understand where everything lives!

## 🏢 Root Directory 
The root directory (`/Users/adriyogayen/Documents/skill/new_feature_project`) contains the core configuration files for both the frontend and the backend.

- `pubspec.yaml` - **Flutter Config**: Defines all the dependencies, packages, and assets (like fonts and images) used by the Flutter frontend.
- `vercel.json` - **Deployment Config**: Configuration used when deploying the backend to Vercel.
- `nutrix_auth.db` - **Authentication Database**: The SQLite database we just created that securely stores user accounts, passwords, and UI preferences.
- `nutrix_rag.db` & `nutrix_web.db` - **Knowledge Databases**: SQLite databases used by the AI to retrieve nutrition facts and web search context.

---

## 🎨 `lib/` (The Frontend)
This folder is mandatory in Flutter. **It contains 100% of the User Interface (UI) and frontend logic.**

- `main.dart` - **The Entry Point**: The very first file Flutter runs to launch the app.
- `login_screen.dart` - **Authentication UI**: The screen where users sign in or register an account.
- `prototype_web_sim.dart` - **Main Dashboard & Chatbot**: This is the primary screen users see after logging in. It contains the Chatbot interface and the main navigation sidebar. *(Note: Even though it has "prototype" in the name, this is your actual production home screen!)*
- `ingredient_scanner_screen.dart` - **OCR / Image Scanner**: The screen where users upload images of nutrition labels for the AI to analyze.
- `diet_planner_screen.dart` - **Diet Planner**: The screen where users input their health stats (age, weight, goals) to generate a customized diet plan.
- `auth_service.dart` - **Security State**: A tiny utility that securely stores the user's JWT (login token) while they are using the app.

---

## 🧠 `Source_Code/` (The Backend)
This folder contains **100% of the Python FastAPI backend and AI logic**. This is the brain of Nutrix AI.

### Core Backend Files
- `api.py` - **The API Server**: The main FastAPI file. It defines all the network endpoints (like `/chat`, `/login`, `/diet-plan`) that the Flutter frontend talks to. 
- `database.py` - **Database Models**: Defines the structure of the user database (tables for users, preferences, diet plans, etc.).
- `auth.py` - **Security Logic**: Handles generating secure JWT tokens and hashing passwords using Argon2.

### AI Capabilities (`Source_Code/nutrix_ai/`)
This subfolder contains the specific intelligence modules:
- `unified_analyzer.py` - **Vision AI**: Handles reading images uploaded from the Flutter scanner and extracting nutritional data.
- `diet_planner.py` - **Diet AI**: Connects to Mistral to generate the structured JSON diet plans.
- `generation/llm_provider.py` - **LLM Connection**: The core file that securely connects to the Mistral API using your API key.

---

## 📂 Other Folders (Framework Generated)
You generally do not need to touch these folders; they are automatically managed by the frameworks:
- `build/` - Contains the compiled, minified version of your app (e.g., `build/web` is what actually gets hosted online).
- `assets/` - Contains raw image files and animations used by the Flutter app.
- `android/`, `ios/`, `macos/`, `web/` - Platform-specific configuration files automatically generated by Flutter.
